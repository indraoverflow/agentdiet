# AgentDiet — website

Product site for [AgentDiet](https://github.com/qansaid/agentdiet), the open-source
Go binary that measures the context an AI coding agent loads before you type.

Dark-first, light theme included, static-rendered, no tracking. Built to be
deployed on Vercel as-is.

```
Next.js 16 (App Router) · React 19 · TypeScript 5.9 (strict) · Tailwind CSS 4
```

## Local development

Requires Node 20.9 or newer.

```bash
cd website
npm install
npm run dev          # http://localhost:3000
```

| Script | What it does |
| --- | --- |
| `npm run dev` | Development server with hot reload |
| `npm run build` | Production build (fully static routes) |
| `npm run start` | Serve the production build |
| `npm run lint` | ESLint with `eslint-config-next` (core-web-vitals + TS) |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run check` | lint → typecheck → build, the pre-deploy gate |

## Where the numbers come from

Nothing on this site is invented, and that is enforced by construction.

`lib/demo.ts` holds the before/after figures shown in the hero, the worked
example and the command explorer. It is generated by running the compiled binary
against a synthetic monorepo fixture, not written by hand. To refresh it:

```bash
# 1. rebuild the CLI (Go 1.22+)
cd .. && go build -trimpath -ldflags "-s -w" -o /tmp/agentdiet .

# 2. recreate the fixture and capture both reports
#    (scripts live outside this repo; the fixtures are documented in
#     the header of lib/demo.ts)
cd /tmp/agentdiet-fixture/before && /tmp/agentdiet . --json > /tmp/before.json
cd /tmp/agentdiet-fixture/after  && /tmp/agentdiet . --json > /tmp/after.json

# 3. regenerate lib/demo.ts from those JSON files
```

If the CLI's output format changes, `components/terminal.tsx` is the one file
that needs updating: `Report` classifies each line (tier header, total, finding,
file row) and colours the label column without re-flowing the text, so column
alignment always matches the real output.

Accuracy rules the site follows, deliberately:

- **No invented metrics.** No star counts, no download counts, no "trusted by",
  no testimonials, no savings percentages applied to anyone's repository.
- **Simulated repositories are labelled as simulated** in the hero, in the
  worked example, and in the terminal footnotes.
- **Roadmap items are not features.** `--since`, `.agentdietignore`, exact
  tokenizer mode and SARIF are described as unshipped.
- **The estimator's error is published**, not hidden: 8.1% MAE, 87% within ±15%.

## Deploying

See [DEPLOYMENT.md](./DEPLOYMENT.md). The short version:

```bash
npm run build
npx vercel deploy --prod
```

Set `NEXT_PUBLIC_SITE_URL` to the canonical origin before building (used for
`metadataBase`, canonical URLs, Open Graph and the sitemap). Without it, the site
falls back to `https://agentdiet.qansa.dev`.

## Accessibility

- One `<h1>` per page, headings in order, landmarks (`header`/`main`/`footer`/`nav`).
- Skip-to-content link as the first focusable element.
- Tab lists use `role="tablist"` with roving `tabindex`, arrow-key/Home/End
  navigation and `aria-selected`/`aria-controls`.
- FAQ uses native `<details>`/`<summary>`; the plus rotates in CSS only.
- Visible focus rings on every interactive element; `prefers-reduced-motion`
  disables reveals and the caret blink.
- Body copy contrast: 7.2:1 (dark) / 6.7:1 (light); the smallest secondary text
  is 5.3:1 and 4.75:1 respectively.
- Theme preference is applied before first paint (inline script), so there is no
  light/dark flash.

## Notes

- `node_modules` inside this folder is ignored by Git. Go tooling walks into it
  if you run `go test ./...` locally from the repository root (you will see a
  `no test files` line for a vendored package); CI is unaffected because a fresh
  checkout has no `node_modules`.
- The site makes no network requests at runtime. The only third-party resources
  are links the reader chooses to follow.
